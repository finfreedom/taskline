# Taskline

**[Открыть приложение](https://taskline-swart.vercel.app)** · [GitHub](https://github.com/finfreedom/taskline)

Минималистичный список задач для тестового задания Junior Vibe Coder. Тёмная графитовая тема, адаптивная вёрстка и сохранение в браузере. Backend, авторизация, платные API и внешние шрифты не используются.

## Возможности

- Добавление кнопкой или клавишей Enter; пустые строки не принимаются, пробелы по краям удаляются.
- Выполнение задачи и возврат в активные.
- Удаление отдельных задач с отменой: кнопка «Вернуть» доступна 8 секунд и восстанавливает последнее удаление, место и статус задачи. При наведении или клавиатурном фокусе таймер приостанавливается; после ухода снова даёт 8 секунд. После перезагрузки возможность отмены не сохраняется.
- Сохранение задач и их статуса в localStorage после каждого изменения.
- Фильтры «Все», «Активные», «Выполненные», счётчики и пустые состояния.
- Сообщение «Всё сделано. Отличная работа!» на 4 секунды после отметки последней активной задачи. При загрузке страницы и удалении задач не появляется; новая активная задача сразу убирает сообщение.
- Управление с клавиатуры, видимый фокус, подписи для скринридера, мягкая анимация галочки и поддержка reduced motion.
- Предупреждение при ошибке сохранения и возможность повторить запись. Повреждённое хранилище не перезаписывается автоматически.

Данные относятся к конкретному браузеру и адресу сайта. Они не синхронизируются между устройствами или вкладками. Очистка данных сайта удалит задачи. При недоступном localStorage изменения могут оставаться только в памяти открытой вкладки — приложение явно об этом сообщает. Лимит названия задачи — 300 символов.

## Стек

React, TypeScript, Vite. Из runtime-зависимостей — только React и React DOM. Playwright используется только для тестов. Точные версии зафиксированы в package-lock.json.

## Запуск

Нужны Node.js 24 и npm. Сборка и браузерные тесты выполнены на Node.js 26.6.0.

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://127.0.0.1:5173).

## Сборка

```bash
npm run build
npm run preview
```

Сборка включает строгую проверку TypeScript. Готовый статический сайт находится в `dist/`. Не открывайте index.html двойным кликом: используйте HTTP-сервер.

## Проверки

```bash
npm test
```

Тесты используют установленный Google Chrome в отдельных временных профилях. Личные профили браузера не затрагиваются. Если Chrome не установлен, установите Chromium командой `npx playwright install chromium` и удалите `channel: 'chrome'` из playwright.config.ts.

Набор тестов проверяет добавление, выполнение и отмену, удаление, сохранение после перезагрузки, фильтры и счётчики, пустые состояния, отмену удаления, таймер и его паузу при фокусе, reduced motion, клавиатуру, длинный текст, отсутствие горизонтального скролла и обработку ошибок localStorage. Основной сценарий также проверяет отсутствие ошибок JavaScript и console.error. Тесты запускаются для настольного и мобильного viewport; мобильная эмуляция не заменяет проверку на физическом смартфоне.

## Результат проверки

- `npm run build`: успешно.
- Playwright: проверены 22 сценария (desktop и mobile): 20 прошли в общем прогоне, ещё 2 — после исправления теста для исчезающей строки в фильтре «Активные».
- Отдельная проверка production-сборки: добавление, выполнение и сохранение после reload прошли; ошибок JavaScript и console.error нет.
- Проверена ширина 320, 390, 768 и 1440 px. Настольный и мобильный интерфейсы просмотрены на скриншотах.
- При установке npm сообщил 0 известных уязвимостей. Это результат проверки на момент установки, не гарантия на будущее.

## Docker (необязательно)

```bash
docker build -t taskline .
docker run --rm -p 8080:80 taskline
```

Откройте http://localhost:8080. Docker не требуется для разработки или статического хостинга. Docker-конфигурация подготовлена, запуск контейнера не проверялся.

## Публикация

Публичный репозиторий: https://github.com/finfreedom/taskline

Ветка: `main`. Проект Vercel `taskline` создан на Hobby. Приложение опубликовано через официальный Vercel CLI: https://taskline-swart.vercel.app

Production-деплой имеет статус READY. Публичный адрес без авторизации вернул HTTP 200; проверены добавление, выполнение, сохранение после перезагрузки, фильтры, счётчик и удаление. Ошибок JavaScript и console.error в этом сценарии нет.

Автодеплой из GitHub пока не подключён: при привязке проекта Vercel сообщил, что в аккаунте отсутствует GitHub Login Connection. Прямой CLI-деплой выбран для текущей публикации. Для будущего автодеплоя сначала нужно связать аккаунты, затем проверить связь репозитория. Повторная привязка без этого изменения не требуется.

Настройки Vercel: framework Vite, build command `npm run build`, output directory `dist`. Приложению не нужны переменные окружения, backend или платные дополнения. Служебная папка `.vercel` исключена из Git.
